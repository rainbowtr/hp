AIカウンセラー - こころパートナー プライバシーポリシー

最終更新日: 2026年10月18日

English

このポリシーは、RAINBOW TREE LLC（以下「当社」）が iOS アプリ「AIカウンセラー - こころパートナー」（以下「本アプリ」）で扱う情報について説明するものです。

いちばん大切なこと
本アプリは AI が返事を書きます。そのため、お客様が送るメッセージと画像、入力したプロフィールは、当社のサーバーと Google の Gemini API に送られます（Gemini API が返事を書きます）。 会話はアプリでもう一度読めるよう、当社のサーバーに保存されます。 会員登録はありません。お客様は端末で作られた番号だけで見分けられ、氏名・メールアドレス・電話番号はお聞きしません。

1. 当社が受け取る情報

何をいつ何のために
端末で作られた番号、国と言語の設定 初めて開いたとき、および通信のたび 会話と設定をひとまとまりにするため
お客様が送るメッセージと返事、選んだカウンセラーと相談の種類、以前の会話の短い要約 メッセージを送ったとき 返事を書くため・履歴を表示するため・会話の流れを保つため
メッセージに添えた画像 画像を添えたとき 画像について返事を書くため・履歴に表示するため
プロフィール（ニックネーム・年齢・職業・状況。入力した場合のみ） プロフィールを保存したとき、およびメッセージを送るたび お客様に合った返事を書くため
お問い合わせの本文と、フォームに入力したお名前・メールアドレス 「お問い合わせ」を送ったとき ご返答のため
利用状況（どの画面・操作をどれくらい使ったか）と不具合の記録（端末の機種・iOS の版・アプリの版） 本アプリを使っている間、および不具合が起きたとき 改善のための統計・不具合の修正

2. AI（Google Gemini）について

返事を書くために、お客様が送ったメッセージ、直近の会話と以前の会話の要約、添えた画像、選んだカウンセラーと相談の種類、入力していればプロフィール（ニックネーム・年齢・職業）を Google の Gemini API に送ります。 また、サービスの目的に沿った相談かどうかを、同じ AI で確かめています。 Google はこれらの情報を、Google 自身の規約とプライバシーポリシーに従って扱います （Gemini API 利用規約・Google プライバシーポリシー）。 本名・住所・電話番号など、ご自身やほかの方を特定できる情報は書かないでください。

4. 広告とトラッキング

プレミアムに登録していない場合、本アプリは Google AdMob の広告を表示します。 本アプリは App Tracking Transparency（トラッキングの許可）をお尋ねします。許可した場合、AdMob が端末の広告識別子を使って、お客様に合った広告を表示することがあります。 許可しない場合も広告は表示されますが、広告識別子を使った個人向けの表示は行われません。この設定は「設定」アプリからいつでも変えられます。

5. 医療ではありません

本アプリは AI の話し相手です。診断・治療・医療上の助言は行いません。 ご自身やほかの方を傷つけてしまいそうなときは、すぐに救急（119）など緊急の窓口に連絡してください。

6. お支払い

プレミアムは Apple が処理する自動更新のサブスクリプションです。当社がカード番号などのお支払い情報を受け取ることはありません。

7. 保存期間と削除

  • 会話・画像・プロフィールは、サービスを提供している間、当社のサーバーに保存されます。
  • アプリで会話を削除すると、アプリからは見えなくなりますが、内容は当社のサーバーに残ります。
  • お客様とデータを結びつける番号は、端末の中にだけ保存されています。アプリを削除するとこの番号も消え、当社のサーバーのデータはお客様と結びつけられなくなります。
  • 会員登録がないため、お名前やメールアドレスだけでは、お客様のデータを特定できません。
  • お問い合わせはご返答のために保存します。利用状況と不具合の記録は、Firebase の保存期間に従います。

8. 第三者への提供

上記の外部サービスを除き、法令に基づく場合を除いて、第三者に情報を提供することはありません。

9. 子どもについて

本アプリは子ども向けではなく、子どもの情報を意図して集めることはありません。

10. このポリシーの変更

変更はこのページでお知らせします。

11. お問い合わせ

アプリの「設定」→「お問い合わせ」からご連絡ください。
